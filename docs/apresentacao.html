Contexto e Problema

🏥 Cenário

  • Hospital universitário com modelos preditivos de diagnóstico oncológico
  • Dataset Breast Cancer: 4.024 pacientes, 16 variáveis clínicas
  • Target: sobrevida — Alive ou Dead

⚠️ Desafio

  • Dataset desbalanceado: ~85% Alive / ~15% Dead
  • Classe Dead é a clinicamente prioritária (não pode ser ignorada)
  • Hiperparâmetros padrão não são suficientes

🎯 Objetivos

  • Módulo 1: baseline com 3 classificadores clássicos
  • Módulo 2: otimização via Algoritmo Genético
  • LLM: laudos interpretativos em linguagem natural
  • Comparar métricas antes e após otimização
⚠️ As saídas da LLM são de apoio à decisão clínica e não substituem o profissional de saúde.

Representação Genética e Operadores

🧬 Cromossomo (5 genes)

GeneEspaço de busca
C0.001 · 0.01 · 0.1 · 0.5 · 1 · 2 · 5 · 10 · 50 · 100
penaltyl1 · l2
solverlbfgs · saga · liblinear
max_iter200 · 500 · 1000 · 2000
tol1e-5 · 1e-4 · 1e-3

720 combinações únicas antes das restrições de compatibilidade penalty × solver

⚙️ Loop Evolutivo

1. Inicializa população aleatória
↓
2. Avalia fitness (5-fold CV F1 Dead)
↓
3. Elitismo → preserva N melhores
↓
4. Torneio → Crossover → Mutação
↓
5. Parada: 30 gerações ou sem melhora em 10
_fix_solver(): garante compatibilidade penalty × solver após cada crossover/mutação. l1 → saga ou liblinear; l2 → qualquer solver.

LLM – Prompt Engineering e Exemplo de Laudo

📐 Estrutura do Prompt

  • Role: assistente de apoio clínico hospitalar
  • Contexto: dados do paciente + predição + probabilidades
  • Tarefa estruturada em 5 seções obrigatórias:
    1. Resultado · 2. Fatores · 3. Interpretação
    4. Limitações · 5. Recomendação
  • Métricas do modelo injetadas: F1=0.3711, ROC-AUC=0.7204, Recall=0.5854
  • Variáveis: ${dados_paciente} · ${predicao} · ${probabilidade_dead}
Decisão: Ollama local (qwen3:8b) — dados clínicos não saem do ambiente, em conformidade com LGPD.

📋 Trecho de Laudo Gerado

"O modelo classificou o paciente como Dead com probabilidade de 78%. Os principais fatores são: estadiamento T3, 12/18 linfonodos positivos e ausência de receptores hormonais. O ROC-AUC do modelo é 0.7204. Recomenda-se avaliação multidisciplinar urgente.

⚠️ Este resultado é exclusivamente uma ferramenta de apoio à decisão. A conduta terapêutica deve ser determinada por profissional de saúde habilitado."

⚠️ As respostas da LLM não constituem diagnóstico médico e não substituem avaliação clínica.

Reprodutibilidade: seed=42 em todo lugar · configs em JSON · LLM mockável · sem valores mágicos no código.

Conclusões

  • O AG converge consistentemente para C=0.1 — regularização forte é fundamental para este dataset
  • ROC-AUC melhora: 0.7185 → 0.7204 com o AG
  • CV F1 melhora: 0.4108 → 0.4160 — melhor generalização
  • Diferentes configurações do AG chegam a hiperparâmetros equivalentes → solução robusta
  • LLM local gera laudos coerentes sem expor dados clínicos
